What it is

OpenLych is a workbench for testing how web requests behave, built, run, and inspected entirely on your own machine.

You build a flow as a top-to-bottom stack of steps (Request, Parse, Set, Key Check, If, Repeat, Result), visually with drag-to-reorder blocks or as KDL text. A job aims that flow at an input list (a wordlist or CSV) and runs it across N runners pulling a shared queue.

Results land in live outcome buckets with per-item detail and captured values. Each list item runs in its own cookie-jar session, so a login's Set-Cookie carries through the item's later requests automatically. It runs as a native desktop window or headless in the browser.

One window, five tabs

Jobs, Configs, Wordlists, Hits DB, and Settings. Build configs, run jobs, and browse results in one place.

Visual flow builder

Stacked blocks with drag-reorder and collapsible branch/loop steps, or edit the same config as highlighted KDL text.

Parallel execution engine

N runners pull a shared queue and sort each item into outcome buckets, with per-item results and captures as it runs.

Four parse modes

Pull values out of a response by JSON path, LR (left/right), CSS selector, or Regex, with prefix/suffix, all-matches, and capture flags.

Full request control

Auto-redirect toggle, templated basic auth, a TLS floor, multipart/form-data bodies, and a per-item cookie jar.

Wordlists & Hits DB

Load txt/CSV datasets as variables; captured hits persist to SQLite with config/type filters and capture search.

Themeable & local-first

Dark/light/system theme, accent and density, engine defaults, and finish notifications, all stored on your machine. No cloud.

How it works

01

Build a flow

Stack Request / Parse / Set / Key Check / If / Repeat / Result blocks. Template fields with {{name}} or <NAME> variables.

02

Point a job at a list

Pick a wordlist or CSV and a runner count. Each line seeds variables; CSV columns become named variables.

03

Run & inspect

Watch outcome counters update live per runner, open any item's detail, and keep the hits you captured.
